# Python Socket Programming

## Overview

A client-server remote command execution system developed in Python using socket programming.

The project demonstrates communication between a client and server over a network connection.

## Features

- Client-server communication
- Socket-based networking
- Remote command transmission
- Server-side command execution
- Command output returned to the client
- Exit command for closing the connection

## Technologies

- Python
- Socket Programming
- Client-Server Architecture
- Subprocess
